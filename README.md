### 💻 Installation

**Mac:**
1. Download `.dmg`
2. Drag to Applications
3. **Important:** Right-click → Open → Open (App not signed by Apple yet - 100% safe!)
   - Or run: `xattr -cr /Applications/PhotoStudio\ Pro.app`

**Windows:**
1. Download `.exe` installer
2. Run installer → Allow if SmartScreen shows
